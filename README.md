# jobhunt
Python scraper using api query authentication to collect job postings matching my specified criteria. 
Scrapper will return jobs with the following information:
date found
date posted
company
job title
link
ATS match scores for each of the skill lists and resumes included in the RESUME class 

Results are fetched and written to a local CSV file. Data is stored and organized in a local Excel file. 

Current API is Adzune free version. 
Working on connecting to a handful more APIs and eventually host the scrapper remotely to run every 2 hours from 7AM to 7PM EST Monday-Friday. 

This scrapper is designed for personal use only and still in a primitive stage.
